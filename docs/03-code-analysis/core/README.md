# 核心组件 (Core Components) 代码分析

本目录包含 nano-vLLM 核心组件的代码分析文档。

## 📁 目录结构

- `llm.py` - 主要的 LLM 接口类分析
- `config.py` - 配置管理系统分析
- `sampling_params.py` - 采样参数配置分析

## 🎯 核心组件概述

### LLM 接口类
- **文件**: `nanovllm/llm.py`
- **功能**: 提供统一的大语言模型接口
- **关键特性**: 模型加载、推理调用、资源管理

### 配置管理
- **文件**: `nanovllm/config.py`
- **功能**: 系统配置参数管理
- **关键特性**: 模型配置、推理配置、硬件配置

### 采样参数
- **文件**: `nanovllm/sampling_params.py`
- **功能**: 文本生成采样参数配置
- **关键特性**: 温度控制、Top-k/Top-p 采样、长度控制

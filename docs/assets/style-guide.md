# nano-vLLM 可视化设计风格指南

## 🎨 设计原则

本项目的所有SVG可视化遵循统一的设计规范，确保专业性、一致性和可读性。

## 🎯 核心设计元素

### 颜色方案 (Color Palette)

#### 主色调
- **深蓝色系**: `#667eea` → `#764ba2` (标题渐变)
- **绿色系**: `#27AE60` → `#2ECC71` (成功/优化)
- **红色系**: `#E74C3C` → `#C0392B` (问题/传统方法)
- **橙色系**: `#F39C12` → `#E67E22` (警告/等待)

#### 渐变定义
```svg
<!-- 标题渐变 -->
<linearGradient id="headerGradient" x1="0%" y1="0%" x2="100%" y2="0%">
  <stop offset="0%" style="stop-color:#667eea;stop-opacity:1" />
  <stop offset="100%" style="stop-color:#764ba2;stop-opacity:1" />
</linearGradient>

<!-- 性能优化渐变 -->
<linearGradient id="performanceGradient" x1="0%" y1="0%" x2="100%" y2="0%">
  <stop offset="0%" style="stop-color:#11998e;stop-opacity:1" />
  <stop offset="100%" style="stop-color:#38ef7d;stop-opacity:1" />
</linearGradient>
```

### 字体规范 (Typography)

#### 字体族
- **主字体**: `Arial, sans-serif`
- **备用字体**: 系统默认无衬线字体

#### 字体大小层级
- **主标题**: `28px` (font-weight: bold)
- **副标题**: `20px` (font-weight: bold)
- **章节标题**: `18px` (font-weight: bold)
- **正文**: `14px`
- **说明文字**: `12px`
- **标注**: `11px`
- **细节**: `10px`

### 布局规范 (Layout)

#### 画布尺寸
- **标准图表**: `1200x800`
- **复杂架构图**: `1200x800`
- **导航图**: `1400x1000`
- **对比图**: `1200x900`

#### 间距规范
- **外边距**: `50px`
- **内容间距**: `20px`
- **元素间距**: `10px`
- **文字行高**: `1.2-1.5`

### 视觉效果 (Visual Effects)

#### 阴影效果
```svg
<filter id="shadow" x="-20%" y="-20%" width="140%" height="140%">
  <feDropShadow dx="2" dy="2" stdDeviation="3" flood-color="#000000" flood-opacity="0.3"/>
</filter>
```

#### 圆角规范
- **卡片容器**: `rx="8"` 或 `rx="10"`
- **按钮元素**: `rx="4"` 或 `rx="5"`
- **小元素**: `rx="2"`

## 📊 图表类型规范

### 1. 架构图 (Architecture Diagrams)
- **用途**: 系统架构、组件关系
- **特点**: 分层结构、清晰连接线、统一色彩编码
- **示例**: `system-architecture-diagram.svg`

### 2. 流程图 (Flow Diagrams)
- **用途**: 数据流程、处理步骤
- **特点**: 箭头连接、时序表示、状态标识
- **示例**: `data-flow-diagram.svg`

### 3. 对比图 (Comparison Charts)
- **用途**: 技术对比、性能分析
- **特点**: 并列展示、量化指标、视觉对比
- **示例**: `paged-attention-visualization.svg`

### 4. 性能图表 (Performance Charts)
- **用途**: 性能数据、优化效果
- **特点**: 柱状图、趋势线、数值标注
- **示例**: `performance-comparison-chart.svg`

### 5. 导航图 (Navigation Maps)
- **用途**: 学习路径、知识结构
- **特点**: 模块化布局、进度指示、交互引导
- **示例**: `feynman-learning-navigation.svg`

## 🎨 设计最佳实践

### 可读性原则
1. **对比度**: 确保文字与背景有足够对比度
2. **字体大小**: 最小字体不低于10px
3. **颜色使用**: 避免仅依赖颜色传达信息
4. **空白空间**: 合理使用留白提升可读性

### 一致性原则
1. **颜色映射**: 相同概念使用相同颜色
2. **图标风格**: 统一的图标设计语言
3. **布局模式**: 相似内容采用相似布局
4. **命名规范**: 统一的ID和类名命名

### 专业性原则
1. **精确数据**: 使用真实或合理的数据
2. **清晰标注**: 重要信息有明确标识
3. **逻辑结构**: 信息组织符合逻辑
4. **视觉层次**: 重要性通过视觉权重体现

## 🔧 技术实现规范

### SVG结构
```svg
<svg viewBox="0 0 1200 800" xmlns="http://www.w3.org/2000/svg">
  <defs>
    <!-- 渐变、滤镜、图案定义 -->
  </defs>
  
  <!-- 背景 -->
  <rect width="1200" height="800" fill="#f8fafc"/>
  
  <!-- 标题区域 -->
  <!-- 主要内容 -->
  <!-- 图例说明 -->
  <!-- 版权信息 -->
</svg>
```

### 代码组织
1. **定义区域**: 所有渐变、滤镜放在`<defs>`中
2. **分组管理**: 使用`<g>`标签组织相关元素
3. **注释说明**: 为复杂部分添加注释
4. **ID命名**: 使用语义化的ID名称
